# Проверка Milestone 1

Проверено в облачной среде 31.10.2026, Node.js 24.19.0, системный Chromium 154.

- `npm test`: 6 выполнено, 6 прошло, 0 пропущено. Границы опыта/остаток/несколько уровней, модификаторы, броня, рост сложности, сохранения и защита будущей версии.
- `npm run build`: строгая проверка TypeScript и production-сборка успешны. Осталось информационное предупреждение о размере Phaser bundle.
- `npm run test:e2e`: движение клавиатурой, убийства автоатакой, настоящий подбор выпавшего кристалла, пауза, три выбора, очередь нескольких повышений, смерть, рестарт со сбросом, рекорд после reload, узкое меню и джойстик прошли. Ошибок JavaScript нет.
- Нагрузочный сценарий просит создать 300 врагов и проверяет ограниченный пул до 240. Во время односекундного наблюдения зафиксирован 61 callback requestAnimationFrame в headless Chromium. Это краткая проверка нагрузки, не гарантия FPS на всех устройствах или длительном забеге.
- Production отдельно запущен через `npm run preview`: загрузка Canvas, старт, ход таймера, пауза/продолжение без исключений. Даже с `?debug` тестовый интерфейс отсутствует.
- Скриншоты меню, арены, улучшений, смерти, мобильного интерфейса и нагрузки лежат в `artifacts/` (игнорируется Git).

Во время разработки исправлены отсутствующие в системном шрифте стрелки/пауза (заменены SVG), нестабильный автопуть в тесте подбора опыта (мелкие шаги к актуальной позиции кристалла) и очистка обработчиков при полном уничтожении Phaser, которое может обходить событие SHUTDOWN.

Не проверены: длительная сессия 15–20 минут, Safari/Firefox и физические телефоны. Не реализованы: классы 2–4, инвентарь, таланты и питомцы; это будущие этапы, а не скрытые части текущего прототипа.
