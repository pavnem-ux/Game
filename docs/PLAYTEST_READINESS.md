## Debug only (`/?debug`, DEV or explicit QA build)

Time scale ×1/×2/×4/×8 (same simulation), God Mode, kill all on screen (normal deaths),
debug overlay (FPS, enemies, seed, 5 s DPS, damage per source), simulate a crash, load a report →
import its save (normal validated import), start the selected map with a seed. `npm run
test:production` asserts none of this reaches the production bundle.

## Architecture

- `src/gameplay/run-stats.ts`: read-only consumer of recorded world events. Damage attribution
  is additive metadata in `SkillEngine`/`SynergyResolver` (attack snapshot → `skill:`/`synergy:`
  source); basic weapon hits come from weapon `impact` events.
- `src/gameplay/rng.ts`: the three seeded streams (combat, skills, spawn) with byte-identical
  formulas to before.
- `src/engine/game-feel.ts`: framework-free pool/flash/shake helpers used by `AlphaScene`.
- `src/gameplay-ui/`: `error-log.ts`, `crash-state.ts`, `CrashGuard.tsx`, `bug-report.ts`,
  `ReportButton.tsx`, `RunStatsPanel.tsx`, `DebugOverlay.tsx`, `ui-settings.ts`,
  `strings-ru.ts` (player text) and `strings-ru-debug.ts` (debug-only text).
- `config/build-info.mjs`: build label defines for Vite and Vitest.

Invariants kept: GameplayWorld is still the only scheduler; Combat Core still owns HP/damage
(debug kills are Core damage); no wall-clock time or `Math.random` in the simulation (seeds are
generated by the UI); rewards are applied once; the save schema only gained an optional field
(version unchanged).

## Known limitations / not verified

- The standard Cloudflare Preview is a production build: debug tools need `npm run dev` or a QA
  Preview.
- FPS was checked only in headless Chromium (software rendering): game feel adds no measurable
  cost; ~17 fps with 108 enemies crowding the player happens before 08.5 too and needs a
  real-device check.
- Individual enemy contact times differ by a few ms between frame sizes (pre-existing; scheduled
  events, rewards and deadlines are unaffected).
- The agent cannot open `*.workers.dev`; the Preview was not checked by the agent.
