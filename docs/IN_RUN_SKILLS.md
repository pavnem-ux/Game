# Task 07 — In-Run Skills

Система навыков забега по спецификации Task 07 v1.0. Четыре класса, у каждого 6 автоматических
навыков и 1 классовая пассивка, плюс 9 общих пассивок — всего **37 определений** по **5 рангов**.
**12 синергий** срабатывают по событиям боя и тегам. Повышение уровня забега ставит игру на паузу и
предлагает до трёх карт; за забег есть 3 переброса. Все числа баланса — **предварительные**
(provisional) и вынесены в данные.

## Как проверить

```bash
npm run dev            # затем /?debug → DEV · Тестирование
npm run test:skills    # Vitest: каталог, предложения, бой, синергии, мир
npm test               # все наборы
```

DEV-команды (`window.__alpha.command`, только development): `grant-xp`, `choose-skill {card}`,
`reroll-skills`, `grant-skill {skillId, rank}`. `grant-skill` выдаёт навык напрямую, соблюдая
класс, слоты и ранги, — для проверки рангов V без долгой игры.

## Архитектура

Новый модуль `src/skills/` не зависит от Phaser и React. В `GameplayWorld` он подключён как
ещё один **граничный модуль** с тем же контрактом peek/advance/resolve. Своих часов и
`update(dt)` у него нет.

| Файл             | Ответственность                                                                                                             |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `types.ts`       | `SkillDefinition`, теги боя, карты, снимки, события навыков                                                                 |
| `config.ts`      | Правила забега (слоты 4/6, 3 переброса, ранг V), бонусы, лимиты Slow/Stun, параметры синергий, `cumulativeRanks`            |
| `catalog/*.ts`   | 37 определений: параметры каждого ранга и описания рангов. Каталог проверяется при загрузке (`validateCatalog`)             |
| `offers.ts`      | Чистый сервис предложений: пулы, управляемый рандом, переброс, бонусные карты                                               |
| `RunSkills.ts`   | Состояние навыков забега: ранги, слоты, переброски, очередь уровней, текущее предложение, золото. Удаления и замены нет     |
| `SkillEngine.ts` | Автонавыки (кулдауны, цели), конвейер попаданий, Slow/Stun, метки, баффы, зоны, отложенные действия, барьер, характеристики |
| `abilities.ts`   | Поведение 28 классовых навыков: только выбор цели и последовательность, все числа из каталога                               |
| `synergies.ts`   | 12 правил синергий с кулдаунами на цель и защитой от рекурсии                                                               |
| `stats.ts`       | Композиция характеристик: Character Stats (без лимитов) + модификаторы забега → центральные лимиты один раз                 |

### Аддитивные расширения существующих модулей

Старые сигнатуры и поведение без новых параметров не изменились.

- **Combat Core.** `AttackRequest.criticalChanceBonus` даёт бонус к шансу крита на одну атаку,
  общий лимит 75% сохраняется, бросок по-прежнему один. `resolveAttack(attack, target,
{ damageMultiplier })` — множитель урона по конкретной цели: метки, фокус. Добавлены
  `setBarrier`/`getBarrier`: барьер поглощает прямой и периодический урон до HP, а поле
  `absorbed` появляется в результате только когда оно больше нуля. Core по-прежнему единственный
  владелец HP и урона.
- **Weapon Attacks.** `launchProjectile`: снаряды навыков летят через тот же движок со
  swept-коллизиями, с необязательным пробиванием (`pierce`, каждая цель поражается не больше
  одного раза). Опция конструктора `damageModifier` — чистая функция множителя по цели для
  попаданий оружия.
- **Enemy AI.** `setControl(id, { movementMultiplier, stunned })` применяется только на границах
  событий. Оглушённый враг не двигается и не начинает атак; уже выпущенные снаряды летят дальше.
  Поле `control` появляется в снимке врага, только пока на него действует контроль.

### Общая хронология (обновлённый порядок при равном времени)

1. Ввод и движение (сбор кристаллов, повышение уровня).
2. Летящие вражеские снаряды.
3. Летящие снаряды игрока, включая снаряды навыков.
4. Тики статусов.
5. Перерасчёт движения AI.
6. Удары оружия игрока.
7. **Действия навыков:** отложенные импульсы, тики зон, активации (новое, ранг 5.5).
8. Атаки врагов.
9. Истечение статусов.
10. **Истечение Slow/Stun, баффов, меток, барьера** (новое, ранг 8.5).
11. Подкрепления.

Активация автонавыка — оппортунистическое событие: готовность определяется кулдауном и наличием
цели в текущей геометрии и проверяется на каждой границе, так же как цикл оружия.

### Конвейер попадания и синергии

Для каждого прямого попадания (оружие, навык, снаряд) соблюдается один детерминированный
порядок:

1. Снимок цели до удара: её статусы, Slow, Stun, метка, % HP, позиция.
2. Урон через Core.
3. Мировой конвейер смертей и наград (`forwardCombat`).
4. Эффекты самого удара (Burn, Slow, Stun…), только если цель жива.
5. Реакции пассивок, синергии и правила убийства.

Синергии читают только **теги** (`fire`, `ice`, `melee`, `heavy_melee`, `dagger`, `projectile`,
`basic`, `secondary`, `synergy`) и снимок статусов, а не ID навыков. Урон от proc'ов синергий и
вторичные удары (искры Fireball, всплески, финальные взрывы зон, бонусные стрелы, добивания)
помечены `procs: false`. Они не вызывают ни синергий, ни реакций пассивок. Стаки, наложенные
синергиями, получают `originId: synergy:<id>`; убийство только такими стаками не запускает
повторное распространение (Wildfire и Plague Chain не образуют каскада).

Смерть от тика статуса тоже обрабатывается: эффекты «непосредственно перед смертью» — это
группы, снятые со статусом `target-dead` в том же пакете событий.

## Цикл повышения уровня

- Каждый новый уровень забега добавляет один выбор в очередь. Если одно начисление XP даёт
  несколько уровней, все выборы ставятся в очередь. Мир останавливается на моменте сбора
  кристалла: завершаются только события этого же момента, и до последнего выбора ничего не
  двигается.
- Предложение содержит до 3 уникальных подходящих карт. Подходят 7 навыков своего класса и
  9 универсальных:
  - новый активный навык — только если занято меньше 4 активных слотов;
  - новая пассивка — только если занято меньше 6 пассивных слотов, классовая пассивка тоже
    занимает слот;
  - улучшение — только если ранг меньше V.
- **Управляемый рандом.** Если доступны и новые навыки, и улучшения, в предложении всегда есть
  хотя бы один новый навык и одно улучшение, третья карта — из оставшихся. Порядок карт
  перемешивается. Если доступна только одна категория — до трёх карт из неё; если кандидатов
  меньше трёх — показывается меньше карт.
- **Переброс.** 3 за забег, тратит один заряд и не даёт лишнего выбора. Новое предложение
  по возможности не повторяет отклонённые карты, но только если это не нарушает гарантии и не
  уменьшает число карт; иначе повторы разрешены. Переброс недоступен, если зарядов нет или если
  кандидатов не больше, чем показанных карт.
- **Исчерпание.** Когда заняты все 10 слотов и все 10 навыков на ранге V, предлагаются три
  повторяемые награды: Восстановление (лечение на 30% Max HP, не выше Max HP), Барьер (щит на
  20% Max HP, 12 с) и Золото (+25 золота забега). Если пул пуст раньше (ошибка данных),
  показываются эти же награды и записывается событие `skill-pool-warning` — интерфейс не
  блокируется.
- **Окончание забега.** Отложенные выборы сбрасываются. Воскрешение сохраняет навыки и очередь:
  выбор показывается после воскрешения. Новый забег начинается без навыков и с 3 перебросами.
- Отдельного сохранения забега в проекте нет. Навыки живут только в текущем мире, и новое
  сохранение специально для этой функции не вводилось.

## Slow и Stun

- **Slow.** Действует сильнейшее активное замедление со сроком до самого позднего окончания.
  Предел — 60% (`CONTROL_RULES.maxSlow`), с учётом бонуса Elemental Mastery.
- **Stun.** Не дольше 1.5 с. После окончания стана враг невосприимчив к новому стану 1.2 с, а
  повторный стан во время текущего отклоняется. Так исключается бесконечный стан-лок. Боссов
  в альфе нет, поэтому отдельного масштабирования для боссов нет; при их появлении его можно
  добавить в `CONTROL_RULES`.
- Freeze и Knockback не добавлялись.

Одно попадание может вызвать несколько разных синергий, но каждую — не больше одного раза.

**Важно для баланса.** Синергии активны всегда, по спецификации им не нужны выбранные навыки. А
у базового оружия альфы уже есть эффекты при попадании со 100% шансом: Burn у Мага, Poison у
Лучника, Bleed у Воина и Разбойника (`defaultOnHit`). Поэтому часть синергий работает с первых
секунд забега:

- Wildfire и Plague Chain — от убийств базовым оружием;
- Deadly Precision — от серии попаданий базовым луком;
- Blood Frenzy, Deep Wounds и Final Cut — от базовых кинжалов;
- Battle Momentum — от убийств мечом.

Это соответствует тексту спецификации, но заметно меняет ранний баланс и требует решения
владельца.

## Настраиваемые параметры (все предварительные)

- **Навыки.** `src/skills/catalog/{mage,warrior,archer,rogue,universal}.ts`: для каждого из
  37 навыков — полный набор числовых параметров каждого ранга (кулдауны, дальность, радиусы,
  коэффициенты урона, длительности, параметры DoT, Slow, Stun, число снарядов, пробивание,
  лимиты ударов, пороги, внутренние кулдауны) и текстовые описания рангов.
- **Правила забега.** `SKILL_RULES` (`config.ts`): слоты 4/6, 3 переброса, ранг V, размер
  предложения 3.
- **Бонусы.** `BONUS_REWARDS` и `BONUS_TUNING`: Recovery 30%, Barrier 20% на 12 с, Gold 25.
- **Контроль.** `CONTROL_RULES`: предел Slow 60%, Stun не дольше 1.5 с, иммунитет 1.2 с.
- **Синергии.** `SYNERGY_TUNING`: коэффициенты, радиусы, число целей, окна, пороги,
  кулдауны на цель.
- **Стрелы Multishot** берут скорость, радиус и дальность из конфигурации лука.
- **Масштабирование.** Радиусы круговых областей масштабируются характеристикой Area Size
  (`scaleCircularAoeRadius`), кулдауны — Cooldown Reduction (`scaleCooldown`).

## Ограничения

- Весь баланс предварительный. Длинные забеги на 15–20 минут не проверялись.
- Золото копится только в счётчике забега: экономики и магазина в проекте нет.
- Визуализация процедурная и простая: зоны, вспышки, метки, индикаторы Slow и Stun, кольцо
  барьера, подписи синергий. Звука нет.
- Поиск скопления врагов (`cluster`) — перебор O(n²) при активации: не больше 120 врагов и
  только раз в несколько секунд. Сетка EnemyAI наружу не открыта.
- Барьер поглощает и периодический урон (DoT), и прямой.
- Hunter's Mark усиливает все атаки лучника, включая навыки; Death Mark — все прямые удары
  разбойника.
- Производительность: замер в Node при 120 активных врагах, 4 активных навыках на ранге V и 4 пассивках —
  в среднем 2.4–3.1 мс на кадр симуляции вместе со снимком; единичные пики до ~35 мс (JIT/GC). На
  телефонах не профилировалось.
- История событий мира по-прежнему ограничена 160 записями. При очень плотных кадрах часть
  эффектов отрисовки может не показаться — на симуляцию это не влияет.

## Ручной QA checklist (для каждого из четырёх классов)

1. Начать забег, собрать XP до уровня 2. Игра останавливается, показано до 3 карт с типом,
   рангом, описанием и счётчиком слотов. Время и враги стоят.
2. Перебросить карты: счётчик 3 → 2, выбор остаётся. На следующих уровнях в предложении есть и
   новый навык, и улучшение.
3. Выбрать активный навык: он срабатывает сам, без клавиш, и не мешает WASD. Пауза (P или Esc)
   его останавливает.
4. Улучшить навык до V. Карта показывает «III → IV» и т. п.; эффект ранга V заметен (см. таблицу
   каталога).
5. Набрать 4 активных и 6 пассивных навыков: новые навыки этого типа больше не предлагаются.
6. С помощью DEV `grant-xp` получить несколько уровней сразу: выборы идут подряд, игра не
   продолжается между ними.
7. Проверить синергии своего класса (подписи над целью):
   - Маг: Frost Nova или Ice Shards по горящим и замедленным врагам;
   - Воин: Ground Slam или Shield Bash, затем удары по оглушённым;
   - Лучник: Toxic Volley или Multishot по отравленным врагам;
   - Разбойник: удары кинжалами по кровоточащим врагам.
8. Умереть с отложенным выбором: после воскрешения показывается выбор; после второй смерти
   выбора нет.
9. Через DEV выдать все навыки до V: предлагаются Восстановление, Барьер и Золото. Барьер
   виден голубым кольцом и в HUD, затем исчезает; золото растёт.
10. Телефонный размер экрана: карты помещаются в одну колонку, панель навыков не перекрывает
    джойстик.
