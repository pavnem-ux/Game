# Плейтест «Последний свет» — инструкция

Эта инструкция — для ручного плейтеста кампании (Task 08) с инструментами Task 08.5. Пройдите
основной путь, отметьте пункты и пришлите файл отчёта и короткие заметки.

## 1. Подготовка

**Где играть**

- **Cloudflare Preview** (ссылка в комментарии бота Cloudflare в PR). Это обычная
  production-сборка, как у игроков: отладочных инструментов и `/?debug` там нет, так задумано.
- **Локально, с отладкой:** `npm ci`, затем `npm run dev` и откройте
  `http://127.0.0.1:5173/?debug`. Появятся кнопка «DEV · Тестирование» и панель «Отладка забега».
- **QA Preview** (если владелец включил её по [GAMEPLAY_BALANCE_QA.md](GAMEPLAY_BALANCE_QA.md)):
  те же инструменты, что и локально.

**Перед началом**

- Запишите версию: внизу главного меню и на экране паузы есть строка `v0.1.0 · <коммит>`.
- Нужен **новый профиль**. Если в этом браузере уже играли, сделайте в «Настройки → Экспорт
  сохранения» резервную копию. Затем откройте окно инкогнито или очистите данные сайта.
- «Тряска экрана» включена по умолчанию; выключается в «Настройках» (раздел «Игра»).

## 2. Основной путь (Definition of Done из Task 08)

Проходится **без отладочных инструментов** (подходит Preview).

- [ ] Новый профиль: главное меню открывается, золото 0, открыта только карта 1.
- [ ] Выбрать класс («Персонаж» или «Играть»).
- [ ] Карта 1: бой, выбор навыков при повышении уровня забега.
- [ ] Открыть синергию: собрать пару навыков, появляется «✦ Синергия открыта: …».
- [ ] Элиты: предупреждение «Элита через …», затем элита с именем и широкой полосой HP.
- [ ] Босс появляется в 10:00 (предупреждение, полоса HP босса, телеграфы атак).
- [ ] Победа: дожить до конца карты **и** убить босса.
- [ ] Экран итогов: опыт класса, золото, уровни, очки талантов, «Открыта карта 2», «Прогресс
      сохранён», блок «Статистика забега», «Сид забега».
- [ ] Карта 2 открыта на «Картах».
- [ ] Перезапустить браузер (закрыть и открыть заново): прогресс на месте.
- [ ] Карта 2 **другим классом**: у класса свой уровень и опыт, золото общее.
- [ ] «Настройки → Экспорт сохранения», затем «Импорт сохранения» этого же файла: подтверждение, прогресс
      тот же.
- [ ] Карта 10 проходима (можно растянуть на несколько сессий; см. ускорители в разделе 5).

## 5. Отладочные инструменты (только локально или в QA Preview, `/?debug`)

Кнопка «DEV · Тестирование» открывает панель:

- **Кампания · профиль:** открыть все карты, установить уровень класса, выдать XP/золото,
  показать сохранение, сбросить тестовый прогресс, сымитировать сбой, загрузить отчёт →
  импортировать его сохранение (с обычным подтверждением).
- **Сид:** «Начать выбранную карту с этим сидом» повторяет забег из отчёта. Тот же сид и те же
  действия дают те же волны и те же карточки навыков.
- **Кампания · забег:** к следующему событию, призвать босса, HP босса → 10%, «Убить всех на
  экране», победа / поражение, ускорение ×1 / ×2 / ×4 / ×8.
- **God Mode:** урон по герою не снимает HP.
- **Панель «Отладка забега»** (слева во время забега): FPS, число врагов, сид, урон в секунду
  за 5 с, урон по источникам.

Все инструменты используют обычные правила игры: награды, убийства и сохранение работают как в
настоящем забеге.

## 6. Как прислать отчёт

1. Когда что-то пошло не так, откройте паузу (P / Esc или кнопка «Ⅱ»). Подойдёт и экран итогов,
   а при сбое — экран «Что-то пошло не так.».
2. Нажмите **«Сообщить о проблеме»**. Скачается файл `skazki-report-ГГГГ-ММ-ДД-ЧЧММ.json`.
3. Пришлите файл разработчику вместе с короткими заметками (раздел 7).

В отчёте есть:

- версия сборки, сид, карта, класс, время забега;
- статистика забега и последние ошибки (до 5);
- сохранение (только игровой прогресс) и строка браузера (user agent).

Личных данных в отчёте нет.

После сбоя сохранение не меняется: текущий забег просто прерывается без записи.

## 7. Что записывать

Для каждой сессии коротко:

- **Версия** (`v… · …`), класс, карта, сид (есть на экране итогов).
- **Интерес:** где было весело, где скучно, хотелось ли сыграть ещё раз.
- **Сложность:** где слишком легко или слишком трудно. Особенно элиты, босс, карты 6–10.
- **Непонятные моменты:** что не объяснено (навыки, синергии, награды, интерфейс).
- **Ошибки:** что произошло, шаги для повторения, файл отчёта.
- **Производительность:** заметные подтормаживания. FPS виден в «Отладке забега», если она есть.

Шаблон:

```
Версия: v0.1.0 · abc1234   Устройство/браузер:
Класс / карта / сид:
Результат (победа/поражение, время):
Интерес (1–5) и почему:
Сложность (1–5) и где:
Непонятно:
Ошибки (+ файл отчёта):
```

## 8. Известные ограничения

- Таланты, снаряжение и траты золота пока заглушки («скоро»).
- Внутри забега нет сохранения: выход или перезагрузка страницы — отказ без награды.
- Баланс предварительный. Названия карт и боссов и графика — временные.
