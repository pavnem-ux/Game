# English glossary (Task 23)

Every proper name and game term, Russian → English, used consistently in the game. Translation keeps
the meaning and the tone (a dark fairy tale), not the words. Ids, save keys and config keys are
unchanged — only display strings change. **For owner review**: rows marked † are proposals worth a
second look.

The tables are machine-readable (`| RU | EN |`): `tests/talents/catalog.test.ts` checks the talent
names against them.

## Formats

- Numbers: `1,240 / 5,000` (comma thousands); decimals with a point (`5.3%`).
- Time: `m:ss` (`1:20`), countdown «Elite in 1:20» / «Boss in 0:45».
- Ranks: Roman numerals I–V (skills), I–III (talents, synergy levels).
