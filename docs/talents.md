## Общие правила

Постоянный уровень класса: 1–50; 1 очко за каждый чётный уровень и +1 дополнительно на уровне 30; всего 26 очков.

Каждый талант имеет ранги I, II, III. Следующий узел открывается после II ранга предыдущего узла; III не обязателен.

Третья ветка доступна после 30 уровня; сверхспособность активируется покупкой I ранга первого узла этой ветки.

Все эффекты применяются только соответствующему классу, сохраняются между забегами и не являются навыками Task 07.

Знаки «+X п.п.» означают прибавление процентных пунктов; «×X» — коэффициент урона; CD — cooldown; AoE — область действия.

Ни один талант сам по себе не разблокирует синергии Task 07.2: по-прежнему нужна пара приобретённых в забеге навыков.

Термины (соответствие тегам кода):
- «кинжалы» — базовая атака кинжалом Разбойника + навыки с тегом `dagger`;
- «стрелы» — базовая атака лука + навыки Лучника с тегом `projectile`;
- «огненные / ледяные навыки» — навыки Мага с тегом `fire` / `ice`; «магические навыки» — тег `magical`;
- «меч» — базовая атака меча Воина (и второго меча после сверхспособности); «melee» — базовая атака меча + навыки с тегом `melee`;
- «прямой урон / прямой удар» — direct hit, не DoT, не отражённый и не вторичный урон талантов.

До реализации проверить отсутствие двойного применения модификаторов, соблюдение лимитов характеристик, DoT (10 стаков каждого типа) и защиты от рекурсивных срабатываний.

## Приложение · Решения G0–G12 / C1–C8

Приоритет: технические решения ниже уточняют одноимённые узлы исходного каталога. Все исходные числа рангов v1.0 сохранены, за исключением явно обозначенных новых параметров и новой локальной механики G11. Пункты, изменённые в v1.2, помечены «(v1.2)». Если трактовка конфликтует с текущим Combat Core, Claude должен зафиксировать конфликт и сообщить, не маскируя его.

### G0 — Approval

Все 168 числовых значений исходного каталога v1.0 утверждены для alpha balancing. Новые значения G1–G12 ниже — явная дополнительная спецификация v1.1, а не якобы ранее согласованные числа.

### G1 — rogue.b3.n01

Poison и Burn базовых кинжалов при проке: Rank I rawDamagePerTick=1.5 за стак; Rank II=2; Rank III=3. Используется обычный 1-секундный таймер DoT. Если разом прокают оба, каждый статус обрабатывается отдельно; шанс наложения на каждое прямое попадание из каталога v1.0.

### G2 — rogue.b3.n01

Длительность каждого нового Poison/Burn: 4 секунды на I–III. Таймер общий внутри каждой группы типа. При добавлении стака обновление срока по существующим правилам Status Effects; длительности отдельных стаков нет.

### G3 — rogue.b2.n03

После успешного Dodge и успешного шанса прока появляется одна неатакуемая теневая копия на фиксированном смещении 45 world units позади игрока; при движении следит за игроком без коллизий. Одновременно максимум 1 копия. Бьёт ближайшего живого врага в радиусе 180 от позиции копии, фиксирует цель на старте удара, один контактный прямой physical hit на 1 атаку, не может накладывать DoT, не запускает синергии и ответные удары. Базовый период атак 1.2 секунды. На Rank I n03 урон копии = physicalDamage игрока ×0.20; на Rank II/III n03 коэффициент тот же, а шанс и lifetime — по v1.0. n04 заменяет этот коэффициент на свой, не суммирует.

### G4 — rogue.b2.n04

Базовый период 1.2 с из G3; Rank I multiplier скорости ×1.00, Rank II ×1.10, Rank III ×1.20. Attack interval =1.2/speedMultiplier. Коэффициент direct damage н04: 0.35/0.50/0.65 × текущий physicalDamage игрока. Копия не критикует и не наследует доп. эффекты основной атаки, чтобы исключить двойной proc.

### G5 — rogue.b3.n04

Explosion radius Rank I=80 world units, Rank II=100, Rank III=130. Урон ×1.5/2.0/2.6 от physicalDamage игрока по каждой цели в радиусе; центр — цель с 10 Poison+10 Burn+10 Bleed, не более одного попадания по цели за один взрыв. CD на инициирующую цель 8 с. Explosion procs=false, DoT не распространяет.

### G6 — warrior.b3.n01

Второй одноручный меч (alpha virtual weapon, без лута): базовый период 1.4 с; радиус атаки/range=100; сектор/arc=100° перед игроком; выбирает ближайшего врага в range и фиксирует направление в начале атаки. Таймер не зависит от основного меча и начинается при запуске забега. Касание одной цели — не более одного попадания за взмах. Отдельные Dodge/Crit/DoT события, но базовые стат-модификаторы применяются один раз. Rank I/II/III коэффициент physicalDamage ×0.45/0.60/0.75 (не множитель к основному мечу).

### G7 — warrior.b3.n02

Применить +8/+15/+22% скорости ТОЛЬКО к базовому offhand интервалу 1.4 с: interval=1.4/(1+bonus). Критические бонусы из n02 II/III применяются после общих модификаторов и caps. Дополнительная общая Attack Speed героя участвует в оружейной формуле один раз, поверх этого talent-specific множителя.

### G8 — archer.b3.n01

Баллиста (v1.2): immobile, неуязвима, не имеет HP; враги не выбирают её целью (ИИ врагов не меняется, он нацелен только на игрока). Base fire interval=1.6 с, range=420, target=nearest enemy (tie id ascending), place=60 units позади игрока по направлению противоположно последнему ненулевому движению; default facing вправо при отсутствии движения. Снаряд: скорость 600 world units/s, hit radius 5, pierce=0, первое столкновение с врагом, не более 1 hit. Нельзя атаковать игрока или другие баллисты. Damage exactly (20+0.15/0.25/0.35×current physicalDamage) на Rank I/II/III ДО сопротивления. Duration/CD строго по каталогу. Entity удаляется по истечении срока или в конце забега.

### G9 — archer.b3.n02

К G8 fire rate 1/1.6 attacks/sec применить бонус +10/+18/+28%; интервал =1.6/(1+bonus). Range Rank I=420, Rank II=462 (+10%), Rank III=495.6 (+18%). Отдельно не наследовать attackSpeed Лучника, кроме явно заданных talent buffs — чтобы stat inheritance не удвоился.

### G10 — archer.b3.n04 (v1.2)

У базового лука нет собственного Poison, поэтому источник свойства — навык «Ядовитый залп» (`toxic_volley`), если он получен в забеге. На n04 II/III каждое прямое попадание баллисты накладывает 1 стак Poison: урон за тик = текущий poisonDamage `toxic_volley` × 0.25 / × 0.40, длительность = текущий poisonDuration `toxic_volley`. Если навык не получен — Poison не накладывается (остаётся только бонус урона +20/+30%). Больше ничего не копируется (не Multishot, не Piercing Arrow, не криты, не метки, не синергии). procs=false: эти стаки не считаются попаданием `toxic_volley` и не запускают Toxic Barrage.

### G11 — archer.b1.n03

Исправить несуществующую потерю урона при пробивании минимальной явной реализацией: для ТОЛЬКО Piercing Arrow базовый falloff 20% за каждое последующее поражение после первой цели (множители 1.0,0.8,0.64,...). Rank I: +1 цель и 20% falloff; Rank II: +2 цели и falloff 15% за шаг (20-5 п.п.); Rank III: +3 цели и falloff 10% за шаг. Прямой урон первой цели и базовые коэффициенты не меняются. Это НОВАЯ механика, ограниченная Piercing Arrow, а не глобальная правка всех снарядов.

### G12 — warrior.b2.n02

Кроме Resistance, отдельный talent-only final direct-hit reduction 2%/4% на Rank II/III; Rank I 0%. Порядок: Combat Core resistance formula → talent reduction множитель 0.98/0.96 → округление один раз и минимум 1 для ненулевого direct hit. Не применять к DoT, unblockable/special scripted damage, а также не превращать в новый stat Armor. Максимум данного таланта 4%; stacking с другими effects — последовательные независимые множители лишь если они реально существуют.

### C1 — mage.b3.n01–n04

Усиленный = единственный активный навык, назначенный в дополнительный 5-й слот при получении пятого distinct active. Пока пятый слот пуст, enhancedSkillId=null и усиления не действуют. Variant B: при ПОЛУЧЕНИИ нового активного навыка можно выбрать, какой из пяти уже приобретённых активных навыков занимает enhanced slot, без удаления/замены. Если 5 навыков уже есть, больше новых активных не приобретается, значит дополнительного произвольного reassign нет. Слоты 1–4 неизменяемы без события приобретения. При выборе 5-го навык по умолчанию назначается enhanced, игроку предлагается разовый выбор среди пяти.

### C2 — mage.b2.n03

Talent barrier и бонусный Barrier используют ОДИН существующий щит/слот: новый барьер ЗАМЕНЯЕТ старый, не складывает HP щита. Если активен более сильный барьер, слабый новый не уменьшает его HP; тогда только продлевает срок до max(existing expiry,new expiry), без добавления прочности. Если новый сильнее — заменяет strength и expiry. Талант срабатывает только после фактически полученного direct hit и если его CD готов; удар, вызвавший барьер, барьером задним числом не поглощается.

### C3 — warrior.b2.n05

Rank I Resistance +5 пока HP строго <30%. Для ranks II/III heal срабатывает при пересечении HP с >=30% на <30% вследствие урона, не просто при старте забега ниже порога. ### C4 — warrior.b3.n03

Перекрёстный удар: физический direct hit с coefficient=0.5/0.75/1.0 от текущего physicalDamage в snapshot (не от базового коэффициента первого меча). ### C5 — rogue.b3.n03

При равенстве минимального количества DoT выбирать в фиксированном порядке Poison → Burn → Bleed, не по случайности и не по дате. Новому стаку задавать rawDamagePerTick из текущего боевого источника этого типа: Poison/Burn — G1 ранга n01, Bleed — текущий on-hit Bleed базового кинжала от «Зазубренных клинков» (`serrated_blades`); (v1.2) если этот навык не получен, Bleed исключается из выбора и сравниваются только Poison и Burn; все исходные player DoT modifiers применяются один раз при создании snapshot. ### C6 — warrior.b1.n05

### C7 — archer.b3.n01–n03
