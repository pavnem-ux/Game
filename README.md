# Fantasy Survivors — Последний свет

Браузерный 2D action roguelite. **Combat Alpha — Task 07:** навыки забега (37 навыков, 12 синергий, выбор на каждом уровне). Ранее, **Task 06:** четыре класса, своё оружие у каждого, melee/ranged враги, Poison/Burn/Bleed, защита после попадания, одно ручное воскрешение, XP-кристаллы, уровни забега, непрерывные подкрепления и DEV-панель для проверки механик. Игра использует все самостоятельные боевые модули на общей хронологии.

## Запуск

Нужен Node.js **24+** и npm. Из каталога проекта:

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. По умолчанию используется порт 5173. Интернет нужен только для установки пакетов: игровой контент работает локально, без CDN, внешних API и ключей.

```bash
npm run typecheck  # строгая проверка TypeScript
npm test           # тесты прототипа + Vitest Stats, Combat, Weapons, Status, Enemy AI и Survival
npm run format:check # проверка форматирования Prettier
npm run build      # TypeScript + production-сборка в dist/
npm run preview    # проверить собранную игру
```

## Публикация в Cloudflare Workers

Игра публикуется как статический Cloudflare Worker `game` через **Cloudflare Workers Builds** из **приватного** `pavnem-ux/Game`: production branch `main`, build command `npm run build`, deploy command `npx wrangler deploy`, root directory — корень репозитория. Что выкладывать (только `dist/`, SPA fallback), задаёт `wrangler.jsonc`. Каждая ветка с PR получает Preview на `workers.dev` (`npx wrangler preview`), ссылку публикует бот Cloudflare в PR. Node.js закреплён в `.node-version` (`24.19.0`). Developer Testing Mode исключён из production и Preview, включая `?debug`.

[Настройки проекта, `wrangler.jsonc`, откат и checklist проверки](docs/DEPLOY_CLOUDFLARE_WORKERS.md). Настройки хостинга не переопределяют игровые правила.

## Как играть

- Выберите Воина, Мага, Лучника или Разбойника и нажмите «Начать забег».
- WASD / стрелки — движение; атака автоматически выбирает ближайшего допустимого врага. На touchscreen потяните в нижней левой части Canvas.
- P / Esc или `Ⅱ` — пауза. Сворачивание вкладки также ставит игру на паузу.
- При первой смерти доступны Revive и End Run. Revival продолжает тот же мир с половиной Max HP и 3 секундами полной защиты; повторная смерть завершает забег.
- Враги оставляют XP-кристаллы: подойдите, чтобы собрать. Каждый уровень забега останавливает игру и предлагает до трёх карт навыков: новый навык или следующий ранг уже выбранного. За забег — 3 переброса, 4 активных и 6 пассивных слотов. Выбор навсегда до конца забега.
- После стартовой группы продолжают приходить melee/ranged подкрепления за пределами камеры. Частота и размер групп постепенно растут, максимум 120 активных врагов.

Для **Developer Testing Mode** запустите dev server и откройте `/?debug`, затем кнопку **DEV · Тестирование**. Панель позволяет выбрать класс/уровень 1–50, повторить тестовую конфигурацию, менять HP, вызывать смерть, добавлять/убирать врагов, проверять стаки/таймеры всех трёх эффектов, настраивать on-hit, защиту и паузу, выдавать тестовый XP и настраивать непрерывные волны. В production этих UI/команд/глобальных debug API нет.

[Полная инструкция альфы, общая timeline, provisional values и тестовый checklist](docs/PLAYABLE_COMBAT_ALPHA.md).

Первый прототип сохранён отдельно по **`/?prototype`**: один маг, XP-кристаллы, mid-run upgrades и прежняя система временных характеристик. В альфе теперь собственный XP забега; старые XP/stat-upgrades не смешиваются с Character Stats. Его debug route — `/?prototype&debug` в development.

## Браузерная проверка

При запущенном **dev-сервере** в другом терминале:

```bash
npm run test:e2e
```

По умолчанию тест использует системный `/usr/bin/chromium`. Можно задать `CHROMIUM_PATH` и `GAME_URL`. Команда проверяет и сохранённый прототип, и новую альфу: четыре класса/оружия, реальный урон, interactive DEV, статусы, смерть/Revive в том же мире, вторую смерть, паузу и touchscreen joystick. Старый сценарий XP/upgrades/save также выполняется. Скриншоты сохраняются в игнорируемом `artifacts/`.

В dev-альфе с `?debug` доступен `window.__alpha`; старый `__survivors` остаётся только в dev-прототипе. Production проверяется отдельно после сборки: `npm run test:production` сам запускает локальный preview на порту 4179 и проверяет отсутствие debug UI/API/controller code.

## Ограничения альфы и сохранённого прототипа

Экипировка, инвентарь, деревья талантов, классы сверх четырёх, питомцы и звук пока не реализованы. Текущий рекорд сохраняется в localStorage этого браузера; сохранение самого забега и синхронизация между устройствами не предусмотрены. Никакой внешний аккаунт не требуется.

В новой альфе максимум 120 активных врагов, есть provisional рост подкреплений, но нет боссов, wave completion или victory. У сохранённого прототипа прежние ограничения: 240 врагов, 120 снарядов, 300 кристаллов; его сложность растёт со временем. Финальный 15–20-минутный баланс ещё не проверен. Препятствия декоративные.

Vite предупреждает о крупном bundle из-за Phaser; это не ошибка сборки. Графика процедурная и оригинальная, без ассетов Vampire Survivors. Дальнейшие задачи начинаются только по отдельному запросу.

## Character Stats System v1.0

Добавлен самостоятельный модуль постоянных характеристик четырёх классов на уровнях 1–50, с последующим подключением к альфе в Task 06. Точные формулы, независимый прогресс классов, финальные лимиты и чистые функции проверяются через `npm run test:stats`. [API, структура и будущая интеграция](docs/CHARACTER_STATS.md).

## Combat Core — Task 01

Добавлено независимое ядро боя `src/combat-core/`: сущности с HP, снимки физических/магических атак, один крит на атаку и отдельный Dodge на цель, сопротивление, округление урона, лечение, изменение Max HP и однократные события смерти. Тесты: `npm run test:combat`. [API, порядок расчёта и вопросы интеграции](docs/COMBAT_CORE.md). Подключение к альфе выполнено в Task 06.

## Weapon Attacks — Task 02

`src/weapon-attacks/` добавляет независимые от Phaser выбор целей, циклы sword/staff/bow/dual daggers, секторное melee и swept-коллизии прямолинейных снарядов. Урон делегируется существующему Combat Core. `npm run test:weapons` запускает 107 тестов. [API и модель времени](docs/WEAPON_ATTACKS.md). В Task 02 числа оружия оставались в тестовых fixtures; в Task 06 появился отдельный provisional alpha config и интеграция.

## Status Effects — Task 03

`src/status-effects/` реализует Poison/Burn/Bleed: до 10 стаков на цель/тип, общую длительность, секундные тики, замену старейшего стака и детерминированную очистку. Combat Core расширен методом `applyPeriodicDamage` без crit/Dodge. Для weapon impacts есть отдельный адаптер с явной синхронизацией симуляционного времени. Тесты: `npm run test:status`. [API, контракты времени, события и ограничения](docs/STATUS_EFFECTS.md). Phaser-интеграция не добавлялась; revival реализован отдельно в Task 05.

## Enemy AI — Task 04

`src/enemy-ai/` добавляет framework-independent melee pursuit/contact attacks, ranged approach/attack/retreat, soft separation через spatial grid и собственные вражеские снаряды. Core остаётся владельцем HP. `npm run test:enemies` запускает новый набор. [API, sampling игрока, timing и общая интеграция](docs/ENEMY_AI.md). Старый Phaser-прототип сохранён по `/?prototype`; новая альфа подключает AI через GameplayWorld.

## Player Survival & Revival — Task 05

`src/player-survival/` добавляет 0.3 секунды защиты от прямых попаданий, состояние смерти/решения, одно ручное воскрешение с 50% текущего Max HP, очистку отрицательных эффектов игрока и 3 секунды полной защиты. Есть синхронные policies/notifications для Enemy AI и Status Effects и контракт паузы мира. `npm run test:survival` запускает 65 новых тестов. [API, lifecycle, совместимые расширения и обязательный порядок событий](docs/PLAYER_SURVIVAL.md). Task 05 ограничивался правилами и policies; playable Phaser/UI-интеграция добавлена в Task 06.

## Playable Combat Alpha — Task 06

`src/gameplay/` объединяет все модули через точные event boundaries: сначала общее время без damage, затем одно событие и немедленная доставка результата. Смерть замораживает все часы на одном timestamp; revival не пересоздаёт мир. Добавлены class selection, responsive HUD, pause/revival/end screens, procedural attack/status feedback и development-only testing panel. `npm run test:alpha` проверяет интеграцию независимо от Phaser. [Архитектура, API stepping, управление и ограничения](docs/PLAYABLE_COMBAT_ALPHA.md).

## Experience & Enemy Waves — Task 06.1

`src/gameplay/experience.ts` и `spawning.ts` добавляют collectible XP, отдельный run level и непрерывные подкрепления на общей timeline. Цена следующего уровня: `20 + 10 × (L − 1)` XP; melee/ranged дают 10/15 XP в кристаллах. Первый spawn через 4 с, затем группы по 3–8; каждые 30 с интервал уменьшается на 0.35 с до 1.5 с. Все числа provisional. Normal spawns находятся за текущей камерой; pause/revival сохраняют расписание, XP и кристаллы. [API, правила attribution, лимиты, DEV и проверки](docs/EXPERIENCE_WAVES.md). Навыки добавлены в Task 07 (ниже).

## In-Run Skills — Task 07

`src/skills/` добавляет 37 навыков по 5 рангов (6 активных и 1 классовая пассивка у каждого класса и 9 общих пассивок), 12 одновременно действующих синергий по событиям боя и тегам (требуют приобретённого подходящего навыка; стартовое оружие и его DoT сами их не открывают), Slow и Stun, барьер, повторяемые награды после исчерпания пула и окно выбора навыка с тремя перебросами. Навыки встроены в `GameplayWorld` как ещё один граничный модуль общей хронологии; Core, Weapon Attacks и Enemy AI расширены аддитивно. Все числа — предварительные данные в `src/skills/catalog` и `src/skills/config.ts`. `npm run test:skills` запускает новые наборы. [Архитектура, правила, синергии, параметры, ограничения и QA checklist](docs/IN_RUN_SKILLS.md).

## Task 07.1 — баланс, навыки и QA

Враги двигаются на 20% медленнее и атакуют с интервалом на 30% больше; 18% обычных спавнов — ranged.
Каждый уровень забега лечит 15% текущего Max HP через Combat Core. Меч Воина больше не накладывает
Bleed; кинжалы Разбойника сохранили эффект. Кнопка «Навыки» показывает ранги, описания, кулдауны
и свободные слоты без паузы; HUD округляет только отображение HP. Для Cloudflare Preview доступна
отдельная явная QA-сборка; main всегда собирается без debug. [Параметры до/после, настройка QA,
проверки и ручной checklist](docs/GAMEPLAY_BALANCE_QA.md).

## Task 07.2 — Skills при паузе и QA

«Навыки» доступны в ручной паузе и окне уровня, с возвратом без изменения карт, очереди,
перебросов или хода времени. Категории/пустые слоты заметнее; Stun отмечен золотым «СТАН».
QA показывает точные счётчики/условия синергий и God Mode ON/OFF, блокирующий только потерю
HP и сбрасывающийся на новом забеге. Production не содержит этих QA-инструментов; баланс и
Cloudflare-конфигурации сохранены. [Контракты, тесты и ручной checklist](docs/SKILLS_PAUSE_QA.md).

## Task 07.3 — Навыки на паузе и синергии

Пауза (кнопка, P, Esc) сразу показывает навыки, ранги, кулдауны, слоты, перебросы и раздел
«Синергии»: условие, эффект, статус «Доступна»/«Закрыта», какие навыки её открывают и чего не
хватает. Карты уровня подсказывают «Откроет: …» / «Сочетается с: …». Всё выводится из
`SYNERGY_RULES` и каталога; баланс, синергии и правила выбора не изменены.
[Подробности и checklist](docs/PAUSE_SKILLS_SYNERGIES.md).

## Task 07.2 v2 — синергии парами и прозрачный урон

Каждая из 12 синергий открывается любой из своих пар двух приобретённых навыков (40 пар из
утверждённой книги; активный + активный или активный + пассивный, ранг I+). Об открытии
сообщает «✦ Синергия открыта». Боевые условия и эффекты не изменены. Карты уровня и обзор
навыков показывают рассчитанный для текущего персонажа урон по каждому компоненту (удары,
вторичные эффекты, тики зон, DoT за стак/тик, крит отдельно) по формулам Combat Core.
[Аудит, модель, проверки и отклонения](docs/SYNERGIES_V2_DAMAGE.md).

## Task 08 — кампания (Playable Campaign Alpha)

Главное меню (Играть / Персонаж / Карты / Прогресс / Настройки), 10 карт по порядку: победа =
дожить до конца карты и убить босса (появляется в 10:00), она открывает следующую карту. Элиты
каждые 2 минуты, 10 разных боссов с телеграфируемыми способностями. Постоянный уровень у каждого
класса (1–50), общее золото, сохранение в `localStorage` с резервной копией, экспорт/импорт.
Все числа предварительные: `src/campaign/config.ts` и `src/campaign/bosses.ts`. DEV/QA-инструменты
кампании доступны только с `?debug` в dev/QA-сборке. [Архитектура, баланс, проверки и
ограничения](docs/CAMPAIGN_ALPHA.md).

## Task 08.5 — готовность к плейтесту

## Task 10 — акты II–IV (карты 11–40) и перебалансировка наград

Кампания выросла до 40 карт в 4 актах: I «Забытые сказки» (карты 1–10 без изменений, кроме
перебалансировки), II «Заколдованные земли», III «Мёртвое царство», IV «Последняя сказка». Карты
11–40 длятся 15 минут, босс — в 10:00; сложность растёт от карты 10 (здоровье +0,15, урон +0,10 за
карту, частота волн как на карте 10), элиты чаще (1:45 / 1:30 / 1:15, на картах 25–30 и 35–40 — по
две), 30 новых боссов из существующих приёмов, особенности карт (быстрые враги, больше стрелков,
сильные элиты). Опыт кристаллов −20% (8 / 12, элита +32), золото за победу — своя таблица (карты
11–40: 300 + 15 × (номер − 10)), доля стрелков 12%. На экране «Карты» — вкладки актов и
«Рекомендуемый уровень». Сохранение — схема v3 (старые загружаются без потерь). Все новые числа
предварительные. [Подробности](docs/CAMPAIGN_ALPHA.md#task-10--acts-iiiv-maps-1140),
[журнал](docs/task-10-progress.md).

## Task 11 — снаряжение, магазин и монеты

Полный мета-цикл: в забегах кампании выпадают монеты (их притягивает, как кристаллы опыта), на
экране «Магазин» за золото покупаются предметы, на экране «Персонаж» они надеваются. Четыре слота
у каждого класса — оружие (своё у класса), броня, амулет, кольцо; 85 предметов (17 шаблонов × 5
