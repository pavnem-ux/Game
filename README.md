# Fantasy Survivors — Последний свет

Оригинальный браузерный 2D survivor. **Milestone 1:** один маг, одно оружие (автоматические искры), один тип врага; перемещение, бой, сбор опыта, уровни и выбор улучшений, пауза, смерть и новый забег.

## Запуск

Нужен Node.js **24+** и npm. Из каталога проекта:

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. По умолчанию используется порт 5173. Интернет нужен только для установки пакетов: игровой контент работает локально, без CDN, внешних API и ключей.

```bash
npm run typecheck  # строгая проверка TypeScript
npm test           # тесты прототипа + Vitest Character Stats, Combat Core и Weapon Attacks
npm run build      # TypeScript + production-сборка в dist/
npm run preview    # проверить собранную игру
```

## Как играть

- WASD или стрелки — движение. Атака автоматически выбирает ближайшего врага в радиусе оружия.
- Подходите к зелёным кристаллам, оставшимся после врагов: они притягиваются и дают опыт.
- При повышении уровня время останавливается. Выберите одно из трёх случайных улучшений.
- P / Esc или кнопка `Ⅱ` — пауза. Сворачивание вкладки тоже ставит забег на паузу.
- При 0 HP появляется итог и кнопка нового забега. Временные улучшения сбрасываются.
- На сенсорном экране потяните по левой части арены — появится джойстик.

## Браузерная проверка

При запущенном **dev-сервере** в другом терминале:

```bash
npm run test:e2e
```

По умолчанию тест использует системный `/usr/bin/chromium`. Можно задать `CHROMIUM_PATH` и `GAME_URL`. Тест проверяет движение, автоатаку, подбор настоящего кристалла, паузу, очередь повышений, три варианта улучшения, смерть, сброс забега, рекорд после перезагрузки и экранный джойстик. Скриншоты сохраняются в игнорируемом `artifacts/`.

Только в dev-сборке с `?debug` доступен `window.__survivors`: чтение состояния, ускоренная симуляция, выдача опыта и урона для воспроизводимых сценариев. В production этот интерфейс отсутствует.

## Устройство проекта

- `src/config/` — данные класса, оружия, врага, улучшений и баланс.
- `src/core/` — типы, формулы опыта/характеристик/урона, мост UI ↔ движок.
- `src/engine/` — арена, Phaser Scene и отдельные системы игрока, врагов, боя, опыта.
- `src/ui/` — React-меню, HUD, улучшения, пауза, итоги и оригинальная SVG-иллюстрация.
- `src/progression/` — валидируемое сохранение рекорда, числа забегов и убийств (схема v1).
- [Архитектура, этапы и риски](docs/ARCHITECTURE.md).

## Ограничения этапа 1

Экипировка, инвентарь, деревья талантов, дополнительные классы/навыки, питомцы и звук пока не реализованы. Текущий рекорд сохраняется в localStorage этого браузера; сохранение самого забега и синхронизация между устройствами не предусмотрены. Никакой внешний аккаунт не требуется.

Забег длится до смерти, сложность растёт со временем. Целевая продолжительность будущего баланса — 15–20 минут; длительный баланс ещё не подтверждён игровыми сессиями. Ограничение: 240 активных врагов, 120 снарядов, 300 кристаллов (переполнение объединяет опыт). Препятствия декоративные.

Vite предупреждает о крупном bundle из-за Phaser; это не ошибка сборки. Графика процедурная и оригинальная, без ассетов Vampire Survivors. Этап 2 начинается только по отдельному запросу.

## Character Stats System v1.0

Добавлен самостоятельный модуль постоянных характеристик четырёх классов на уровнях 1–50, без подключения к текущему бою или интерфейсу. Точные формулы, независимый прогресс классов, финальные лимиты и чистые функции проверяются через `npm run test:stats`. [API, структура и будущая интеграция](docs/CHARACTER_STATS.md).

## Combat Core — Task 01

Добавлено независимое ядро боя `src/combat-core/`: сущности с HP, снимки физических/магических атак, один крит на атаку и отдельный Dodge на цель, сопротивление, округление урона, лечение, изменение Max HP и однократные события смерти. Тесты: `npm run test:combat`. [API, порядок расчёта и вопросы интеграции](docs/COMBAT_CORE.md). Подключение к игровому циклу выполняется отдельным этапом.

## Weapon Attacks — Task 02

`src/weapon-attacks/` добавляет независимые от Phaser выбор целей, циклы sword/staff/bow/dual daggers, секторное melee и swept-коллизии прямолинейных снарядов. Урон делегируется существующему Combat Core. `npm run test:weapons` запускает 107 тестов. [API и модель времени](docs/WEAPON_ATTACKS.md). Числа оружия хранятся только в тестовых fixtures; игровой каталог и интеграция со сценой не создавались.
